入门

星辰日志、第一枚透镜、折射望远镜，以及星空下的第一个夜晚。

整个模组从天空开始。日志告诉你下一步做什么，望远镜则打开通往最初几个世界的路。

1. 星辰日志

星辰日志 是引导你玩转本模组的书：章节是道路的分支，阶段是目标。每个阶段都有“该做什么”的提示。日志用一本书和青金石合成：

工作台（无序）

第一次进入世界时，日志已经在你手中。完成一个阶段时，快捷栏上方会有一行字告诉你，并给出下一个阶段的名字。

第一次打开时，日志会询问模组画质：低、中或高。之后可以在模组设置中更改（日志页眉上的齿轮）。

需要用多个方块搭建结构的阶段（较大的望远镜、火箭、射电望远镜、光束发射器、船坞、星门环）在日志中附有示意图：可以旋转，也可以逐层查看。“在世界中显示”按钮会在你前方几步远的地面上（若你看着的方块很近，则在那个方块上）放出该结构的虚影：它自下而上浮现，上方立起一道光柱。只有你能看到虚影。照着它自下而上搭建：最低的未完成层更亮，核心是金色的，被东西挡住的位置显示为红色。如果你当时正看着天空或脚下，快捷栏上方会有一行字告诉你虚影在哪一侧、有多远。日志中的同一个按钮可以移除虚影；结构建成后，虚影会自行消失。

4. 接下来

  • 第一个星座是大熊座。日志会记下你找到的星座，被准星捕捉到的流星会给出星尘——用来换取提示的货币。
  • 月球和第一枚火箭在“火箭”章节等着你：燃料、发射台、舱室。见“火箭与飞行”。
  • 在模组的世界里无法呼吸：你需要宇航服和氧气。
  • 每隔几天就会有一颗陨石落到地球上：如何凭烟柱找到陨石坑、坑里有什么，见“陨石”。
