下界与末地的变化

末地与下界的阶段：缝合之缝与裂缝、熔口出口、新的天气与事件、末地与下界本地的生物，以及服务器主人的开关。

下界和末地不再只是摆放仪器和载具的场地：它们会随着游戏进程而变化。打开的裂隙或熔口、被击败的守护者以及之后的飞行，都会提升世界的阶段——末地岛屿上的缝线裂开，下界的熔口出口变热，它们自己的天气、事件和生物随之到来。仪器的天空和日志是每人各自的，而变化本身由整个服务器共享。

阶段

阶段属于末地和下界本身，而不属于玩家：第一个打开所需之物的人提升它，所有人都能看到变化。阶段只升不降。

阶段末地下界由什么提升
0缝合的末地沉睡的下界世界的初始状态
1末地苏醒下界呼吸裂隙镜中的第一道裂隙 / 熔岩镜中的第一个熔口
2裂隙奔流熔口奔流第二道裂隙 / 第二个熔口
3圆盘之上地渊之上的穹顶击败末影龙并且乘飞船驶入裂隙间域 / 击败凋灵并且乘飞船驶入地渊
4沐光的末地沐光的下界尾声
  • 阶段提升时，该世界中的所有人和打开者都会收到一行提示：是谁打开的，以及世界现在的名字。
  • 旧世界也会跟上：玩家进入末地或下界时，世界会得知他之前打开过什么（裂隙、熔口、飞行、末影龙、击杀过的凋灵）—— 阶段便会落到应有的位置。
  • 最显眼的变化不是遍布整个世界，而是按地点出现：末地是在已开启裂隙所在的那一侧天空，下界是在已开启熔口的生物群系（见下文）。

服务器主人的开关

变化可以关闭：游戏规则“下界与末地的变化”（在“游戏规则”界面或用 /gamerule；26.3 上叫 <模组 id>:nether_end_changes，1.21.1 和 1.20.1 上叫 <模组 id>.nether_end_changes），或在 config/<模组 id>-server.json 文件中写一行 "nether_end_changes": false（服务器启动时读取）。只有两者都开启时变化才会发生。

关闭后，阶段和已开启的地点仍会累积，但世界不显示它们：缝线沉睡，熔口出口冷却，阶段天气和事件不会到来，新生物不会出现，虚空浅滩和巨人发掘停止。重新开启后，一切会在一秒内恢复。管理员可用模组命令 stage end|nether [get|set N] 查看和设置阶段。

下界

下界的生物群系保持不变，但每个熔口都有自己“流入”的生物群系家族：

熔口下界生物群系家族
锻炉下界荒地
灰烬灵魂沙峡谷
菌络绯红森林与诡异森林

熔口出口

下界各处立着熔口出口——由熔口外壳构成的冰冷锥体、裂缝和管道，中间是熔口之喉；下界沉睡时，喉口偶尔会在地下发出沉闷的撞击声（远处也能听到）。

  • 阶段 1——外壳裂成一张炽热的裂纹网，出口喷吐热气，并吐出地渊余烬（附近最多躺着一个）。
  • 热力充能：没有燃料的燃煤发电机 Mk1放在炽热喉口的侧面、上方或上方两格处，会靠熔口的呼吸燃烧；之后喉口冷却一级，几分钟内又会重新变热。
  • 阶段 2 且该家族的熔口已开启——出口明亮燃烧，并在周围长出自己世界的物质（最多六处）：锻炉是镀金熔渣，灰烬是灵魂焦渣和骨块，菌络是绯红菌瘤、诡异菌瘤和荧光菌丝，哀泣是泪脉和哭泣的黑曜石。这样，不用下潜钟也能获得烈火诸界的物质。
  • 日志阶段“熔口出口”——站到出口的外壳上。

事件

  • 熔口贯穿（从阶段 1 起）：在离玩家 40–90 格的野外（不在要塞或堡垒遗迹中），一个新的出口冲破地面——热柱、一圈裂纹、震动——并且留下来。旧世界也会因此出现出口。日志阶段“熔口贯穿”——在它发生时待在附近。
剧透：这里描述了游戏后期才能抵达的地点。
  • 穹顶震颤（从阶段 3 起）：每八秒一次双重撞击；每次撞击前一秒，尘土从穹顶落下——离开它的下方；撞击时玄武岩巨石崩落，最后是一次坍塌：一座带着地渊余烬巢的深层玄武岩土丘。日志阶段“穹顶坍塌”——待在它附近。
  • 从阶段 3 起，在地渊透过下界显露的地方，熔岩海面上会旋转着发光的漩涡。

下界的光也活了：雾和熔岩映在穹顶上的光缓缓变暖又变冷，如同呼吸。这一切都不用着色器，使用光影包时只有雾的颜色会变。

末地

末地按天空的方位变化：从末地中央看去，每个外围岛屿都归属于方位最近的那道裂隙（晶面——西南，虫巢——北，吐息——东，巨眼——东南）。距中央 256 格以内（主岛、黑曜石柱、传送门）不会有任何变化。

缝合之缝与裂缝

外围岛屿上躺着缝合之缝——末地石上几乎不再闷燃的窄裂口，被粗黑的线横着缝住（缝线针脚）；中间是刻着筑环者符号“上”的缝线符记，寂静中传来敲击声。空手使用符记——“向上看”；当它那一侧的裂隙开启时，符记会亮起。日志阶段“缝合之缝”。

  • 阶段 1——在裂隙镜中打开一道裂隙，它那一侧的缝线就会裂成发光的裂缝（裂缝）：裂口上方飘着世界颜色的光幕，地面上蔓延着发光的裂纹。你的裂隙现在也会在末地的普通天空中燃烧。
  • 阶段 2——裂缝呈现自己世界的样貌：晶面的棱镜水晶（棱镜晶簇）、虫巢滴落的蜡（蜡质蜂巢）、吐息灼人的紫色蒸汽（会灼伤没戴头盔站在其中的人）、眨动的巨眼（会传送附近的末影人）。在地平线上，每道已开启裂隙的方向都闷燃着它的颜色。
  • 用镐敲碎裂缝会得到一撮：1–2 个虚空碎片和它所属世界的物质。缝线随即再次裂开——更加愤怒：五分钟内灼伤站在上面的人，也不再给出那一撮。活塞和爆炸推不动裂缝，也无法把它带走。日志阶段“裂缝”。

在变化之前就探索过末地的旧世界里，缝线会直接在玩家身旁裂开。

事件

  • 晶面、虫巢、吐息或巨眼吸气（阶段 2，裂隙已开启）：风朝裂隙那一侧吹，掉落物随之爬行——远离岛屿边缘（潜行和宇航服能稳住你）。最后是呼气：那一侧的裂缝洒出它们世界的物质。
  • 信使聚会（阶段 2）：六只末影人围成一圈把方块搬到裂缝旁。待到结束并且不要直视它们的眼睛——你会得到馈赠：裂隙彼端世界的方块和信使珍珠母。看一眼——整个圈子都会转而对付你。日志阶段“信使聚会”。
剧透：这里描述了游戏后期才能抵达的地点。
  • 碎裂者星雨（阶段 3）：星星从天顶坠落，小块残片砸在玩家附近——留下铺满残片玻璃的坑，偶尔还有核心残块。高潮时，一块 7–10 格高的巨大残片砸进末地石：玻璃外壳包着核心，脚下是碎裂者碑录；一天后它会回到虚空。日志阶段“碎裂者星雨”。
  • 在阶段 3，裂隙间域诸岛的剪影高高出现在末地的天空中。

末地在变化

末地的阶段提升时，末地中的每位玩家都会看到高光时刻“末地在变化”：光转成该阶段的颜色，裂纹图案在末地石上蔓延，天穹上睁开一只放射光芒的眼，碎片飞散，通讯链路传来一行话。

剧透：这里揭示了部分剧情和背景故事。

到了阶段 4，在尾声的光中，裂缝愈合成一道明亮的金色缝线，末地的天空沿地平线泛起暖光；下界的熔口出口燃着均匀的金色，下界的光也变得均匀温暖。

末地与下界的生物

随着变化，末地和下界有了自己的野兽。它们从缝合之缝、裂缝和熔口炽热的喉口中出来（旧世界也一样），也随事件出现；变化关闭时——一只也没有。
