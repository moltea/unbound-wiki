天文望远镜与星空

如何用天文望远镜观测、连接星座、捕捉流星和发现世界。

天文望远镜不会打开任何窗口：它会替换掉世界的天空。你站在望远镜旁转动头部，屏幕中央的准星就会在真实的星空中移动。

上手

要做什么怎么做
开始观测夜晚、露天之下——右键点击天文望远镜
瞄准转动头部：准星始终在屏幕中央
缩放鼠标滚轮
选中一颗星瞄准它并左键点击
画一条星座连线选中一颗星后，瞄准下一颗并点击：选中会移到第二颗星上，因此一个图形可以一笔画完
取消选中右键点击
观看月球或行星瞄准它并按住左键，直到图像清晰
捕捉流星在流星燃尽前瞄准它并左键点击（若准星正下方有星座中的星，则优先选中那颗星）
请求提示当天文望远镜提供提示时，按提示键
结束观测潜行（Shift）

星座

图形都是真实的，不可能全靠猜：大熊座要连七条线，而不是六条——斗口是封闭的。完成的星座会亮起来，星星一颗接一颗点亮；星辰日志会记录下来，之后会开启新的阶段。

星尘与提示

当你卡住时——长时间盯着一个星座却没有画出新连线，或连续出错两次——天文望远镜会提供提示：一块写着按键和价格的牌子。一次提示只揭示一条连线，仍需你亲手画出。提示用星尘支付；星尘来自准星捕捉到的流星和天空中的发现。在创造模式下提示免费。

天空中的世界

月球、行星和遥远的天体并非每台望远镜都能看到：折射望远镜、反射望远镜、天体照相仪和引力镜一台比一台看得更远。星辰日志会记录你找到的天体，之后你就可以飞往那里。每个天体该去哪里找，日志本身会给出提示——本维基不剧透这些答案。

透过玻璃能看到天空，而山、房屋和生物会挡住它——就像真实的天空一样。使用光影包时，望远镜的星空会画在画面之上，照样可用。
