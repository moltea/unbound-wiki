战利品药水与投掷弹

用生物部件以及守卫与世界主宰的战利品酿造与投掷：守卫秘药、世界药水、世界投掷弹、主宰灵药与投掷弹。

生物部件和巢穴守卫的战利品不只用于装备：可以在酿造台中酿造，也可以做成投掷弹投掷。这里的一切都会消耗，所以生物和守卫值得反复狩猎。

守卫秘药

把守卫战利品放进装有三瓶粗制的药水的酿造台，得到三瓶秘药——由两三种效果组成的强力药水，别处无法酿造。火药使其变为喷溅型，龙息使其变为滞留型。

世界药水

世界主宰的战利品

世界主宰可以用供品再次召唤，它的第二件战利品——心、核心、孢子、晶状体、肺——不再白白堆积。第一件用于唤醒星门和打造武器；此后的每一件都可以酿造成主宰灵药（配三瓶粗制的药水得三瓶，比任何守卫秘药都强），或制作成四枚主宰投掷弹：战利品、两份火药和一件原版物品。主宰投掷弹以主宰自己的招式攻击——许多会留在落点再次打击。
