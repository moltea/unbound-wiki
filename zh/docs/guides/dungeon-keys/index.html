地牢钥匙

在每座地牢里到哪儿找楼层钥匙：门的基座会告诉你什么、怎样认出松动的石块，以及守门人之眼藏在哪里。

一个世界的地牢有好几层，每层都有一道通往下方的门。有的门由谜题（镜子、符文板）或本层的守卫把守，有的则由拱心石基座把守：它在等一把钥匙，没有钥匙就无法继续前进。钥匙无需合成：它就在同一层、在它自己的房间里，而且不用打开那道门，从本层的入口就能走到那个房间。

门的基座会告诉你钥匙在哪

空手（或拿着任何不是钥匙的东西）按下基座。准星下方会出现两行字：

  • 第一行说明基座要的是哪把钥匙：“锁座正等待它的钥匙：……”（用 Jade 或 WTHIT 看向基座时也会显示这一行）；
  • 第二行是青绿色的，说明钥匙在这一层的哪个房间、藏在何处，例如：“钥匙就在这一层的‘守门人居所’里：藏在墙上刻着的眼睛下方松动的石块后面……”。

基座不会告诉你通往那个房间的路。房间的名字说明了里面有什么（库房、柜子、小室、工坊、居所）——在这一层找一间那样陈设的房间；诵经台上的本层记录也常常暗示钥匙由谁保管。拿到钥匙后，用它按下基座：钥匙嵌进基座，通往下方的门就会打开。

松动的石块

钥匙最常被封在墙里松动的石块后面。只要知道看什么，隔着四五步就能认出来：

  • 每一道接缝里的灰浆都已碎落，接缝发黑，石块歪斜，上面有一道裂纹；
  • 接缝里闪着火星，缝隙中有气流吹出——每个敞开的面都有灰尘飘出；
  • 偶尔会有砂砾从缝里悄悄落下——能听见；
  • 在 Jade 和 WTHIT 里，它的名字和普通砌墙一样，但名字下面有一行“石块松动：用手一按就会让开”。

怎么打开：右键点击它——空手或手里拿着东西都行（只是不要拿着东西潜行）。石块会崩落，后面是一个放着箱子的壁龛。不需要镐，冒险模式下也可以。地牢主宰活着时压在你身上的挖掘疲劳，不会妨碍打开松动的石块。

并非每处松动的石块后面都藏着钥匙：存放补给的暗格（房间的记录会提到它们）以及通往相邻房间的暗道，也是这样封起来的。钥匙就在基座告诉你的那一处后面。

“世界中的物品”是指并非为地牢专门打造、而是在世界里就能找到的钥匙（核心、腺体、羽毛、甲片）：基座接受任何同样的物品，不只是钥匙房间里放的那一件。地牢自己的钥匙（眼、岩芯、封印、冰雹等）都放在钥匙房间里。

守门人之眼

守门人之眼 是月球透石膏地下墓穴第四层（墓城）那道门的钥匙。没有它，就打不开墓城之门，而月球的主宰就沉睡在门后。守门人之眼无需合成：它被封在同一第四层“守门人居所”的墙里。

怎么找：

  1. 下到第 4 层，按下墓城之门的基座——青绿色的那一行会说出守门人居所。
  2. 在这一层四处走走：守门人居所是一间小房间，不用打开那道门，从第 3 层下来的楼梯就能走到。里面有一把面朝墙壁的石椅、角落里的床铺、一张放着诵经台的桌子，以及守门人为自己准备的石棺。一只猎手守着这个房间。
  3. 石椅前方的墙上刻着一只眼睛，瞳孔闪着光。就在它的正下方是松动的石块：碎裂的接缝、火星、气流。诵经台上守门人的记录也是这么说的：眼被砌在了“它自己的标记之下”，在一推就松的石块后面。
  4. 用手按下眼睛下方的石块——它们会崩落，后面的壁龛里有一只装着守门人之眼的箱子。
  5. 回到基座，把眼嵌进去：通往主宰的门就会打开。

这个房间里也可能有别的松动石块——那是通往隔壁房间的暗道。守门人之眼就在眼睛标记的下面。

钥匙不见了，或者地牢是旧的

  • 旧版本模组生成的地牢。 在这一提示出现之前就已生成的地牢里，基座的提示同样有效：世界里的基座记得自己的分组，而文字来自翻译。按一下基座——青绿色的那一行就会出现。
  • 箱子是空的。 钥匙房间的箱子只给一把钥匙，多人游戏中谁先打开谁就拿走。问问同伴：也许钥匙已经在他们手里，或者门已经打开了。
  • 钥匙丢了。 一个世界不止一座地牢。同一世界另一座地牢里的钥匙也能用在这个基座上：基座检查的是嵌进去的是什么物品，而不是它来自哪个箱子。属于“世界中的物品”的钥匙，重新采集就行。
  • 这一层没有那个名字的房间。 在新版本的地牢里，钥匙房间一定会生成；如果旧版本生成的地牢里没有它，就去同一世界的另一座地牢拿钥匙。
