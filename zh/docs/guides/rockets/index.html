火箭与飞行

燃料、发射台、组装火箭，以及飞往你发现的世界。

通过天文望远镜发现的世界可以亲身前往。火箭分为四个等级：登月、行星际、重型和深空——一级比一级飞得更远。

…

你需要什么

  • 燃料厂——燃料：打开燃料厂，放入煤炭和空罐（两块煤炭装满一罐）；漏斗可以像对箱子一样对它输入输出。
  • 充电站——充电：白天在露天下为空电池充电，每块半分钟。每次飞行消耗一块电池。
  • 发射台板——发射台；火箭在上面组装，发射时不会把它带走。
  • 电池块也能用基地机器的电网给电池充电，见“机器与能量”。

飞行

  1. 在发射台上自下而上搭建火箭——日志里有布局；最后一个方块放好后它会自行组装（登月火箭的最后一块是舱室上方的鼻锥）。储箱正面的表显示燃料，尾翼上的灯和舱室舷窗显示电量。各级火箭远远就能凭轮廓分辨：登月火箭矮胖，立在四片红色尾翼上；行星际火箭高挑，有两台助推器、一条黑色防热带，太空舱上方还有逃逸塔；重型火箭是一座粗塔，立在由四台助推器组成的白色“裙摆”上，有一段棋盘格舱段和一个圆钝的红色鼻锥；深空火箭则是一艘装有五台发动机的飞船，带球形储箱、居住环（有电时会旋转），顶上还有天线碟。重型和深空火箭的表显示的是氦-3，喷口上方的线圈环会发出橙光。
  2. 坐进舱室，打开星图：只能飞往通过天文望远镜发现的世界，并且火箭上方必须是露天。
  3. 火箭会降落在它上次在那个世界停靠的位置；在新世界，它会寻找一块平坦的空地。它不会破坏任何东西，也绝不会落在熔岩中间：舱门外总有坚实的地面，它也会避开金星的熔岩海。

出发前就备好回程的东西。对于选中的世界，星图会告诉你从那里起飞需要什么：回程燃料、一块充能电池（飞行会耗尽它，而登月火箭只有一个电池位）、返回级（新世界没有发射台，而已着陆的火箭下面也没法再建一个）——还有着陆支架：没有它们，只有舱室会降落下来，储箱也是空的。回家的路程同理，火箭会飞回自己的发射台。发射台上的火箭也可以通过管道加注——借助加注塔和充电塔。

模块

火箭船体上有模块插槽：登月火箭两个，行星际火箭三个，重型火箭四个，深空火箭六个。手持模块对船体上的插槽使用即可装上（潜行时空手点击可卸下），也可以把它放进舱室窗口的模块槽。每个模块都会显示在火箭本体上，远远就能认出：

  • 火箭模块：着陆支架——两条向两侧张开、带脚掌的支腿，装在黄黑条纹的外壳下：整枚火箭都会着陆，而不只是舱室。
  • 火箭模块：返回级——一枚架在黑色喷管上的小火箭：无需发射台，从空地上就能起飞。
  • 火箭模块：货舱——铁盖下一只用箱子木板做的货箱：九格货物。
  • 火箭模块：乘客座椅——一个带舷窗的凸包，透出暖光：能多坐一名乘客。
  • 火箭模块：附加储箱——一只带红色箍带的桶，观察窗里燃料在发光：燃料多一半。
  • 火箭模块：电池组——一个铜柜，带两个接线柱和红色电量条：多两个电池位。
  • 火箭模块：太阳能阵列——两片蓝色翼板：停在露天下时，火箭会慢慢给自己充电。
  • 火箭模块：生命维持模块——一台风扇，下面泛着蓝色的空气光：在舱室里和着陆的火箭旁都能呼吸。
  • 火箭模块：推进级——一对白色助推器，飞行中也会点火：每次飞行的消耗减少五分之一。
  • 火箭模块：地表扫描仪——一只白色碟盘，镜头一闪一闪：着陆后会告诉你最近的聚落在哪个方向。

梭舟与下潜钟

幽暗之路和烈火之路没有火箭：梭舟前往裂隙后的世界，下潜钟下到熔口的底部。载具能去哪里由模块决定：通往下一个世界的模块，要用上一个世界的战利品制作。模块装在载具本体上：手持模块点击船体上的插槽（潜行时空手点击可卸下）。每次从末地或下界出发都要消耗一卷丝线或一条余烬淬火链，以及与世界距离相应的燃料；而沿着丝线或锁链返回则是免费的，会回到它的泊位或绞盘。世界与世界之间的旅程会把两段距离加在一起，可能超出储箱容量（从虫巢到巨眼需要 12，而储箱只有 10）：这时先回家。载具的控制台只有在补给足以到达至少一个已发现的世界时才会显示“准备出发”；否则会告诉你缺什么：“液态珍珠不足：最近的世界需要 3”。

接下来

  • 第一次发射前——“氧气、宇航服与气候”：在模组的世界里无法呼吸。
  • “机器与能量”——燃料和电量从哪里来。
  • 到达后你会遇到“民族与任务”、“地牢与世界主宰”和“星门”。
  • 梭舟和下潜钟各从自己的仪器开始：“裂隙镜”和“熔岩镜”。
  • 之后，你自己的飞船会取代火箭：“飞船与太空”。
