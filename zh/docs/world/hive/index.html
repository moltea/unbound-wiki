生物

巢脾雄蜂巢脾守护者虫巢守卫蜡蛴螬

民族

  • 巢脾守护者 — 留在虫巢里的潜影贝亲族：女王合上外壳、巢脾不再飞行之后，他们没有离开。每个家族守着自己的一块巢脾，封自己的蜡，卖自己的琥珀，拿封好的巢室来数家产；他们的壳本身就是巢室，受了惊吓会“砰”地盖紧盖子。迎接客人时，他们像脱帽那样掀起盖子；他们管人类叫“无盖者”——脑袋永远朝天敞着，在他们眼里勇敢得吓人。
  • 守护者巢脾。巢脾守护者的聚落：琥珀蜡质的家族巢室簇拥着女王宫廷，每间都盖着半掩的盖子，如同守护者自己的壳，家族封存的巢室嵌在墙里，供所有人点数。宫廷中央，小王台悬在琥珀华盖下，华盖下的蜡烛永不许熄灭。

结构

琥珀塔

一座巢脾壁筑成的尖塔，微微向东倾斜，塔身嵌满琥珀，越近塔顶越密。没有人建造它：虫巢会渗出树脂，历经数百年，树脂变硬成琥珀，琥珀越积越多。塔内的空腔摸上去是暖的。

巢脾之桥

一跨紫珀台阶与砖栏杆，架在两根巢脾柱之间，中间微微拱起。巢脾还会飞的时候，这样的桥把它们连在一起，让雄蜂不用翅膀也能过去。这一座比它的巢脾活得更久；中间的缺口是新的。

雄蜂栖台

一根孤零零的巢脾壁立柱，在三个高度伸出台阶枝杈，每根枝杈末端是一个盛着蜡的小平台。雄蜂在巢脾之间在此歇脚，把蜡留在栏杆上。有一根枝杈已经断了，其余的还撑得住。

星门

与地球上的那座一模一样的环，立在本地岩石砌成的基座上，染着这个世界的颜色：布设星门的人，是在每个世界同时动的手。这一座仍在沉睡。唯有击败了此界主宰、并熬过它的试炼的人，才能唤醒它；届时请将主宰之心、道路之尘和这个世界所赐之物放入环中，它便会加入其他已苏醒的星门。

紫珀拱门

一座孤零零立着的紫珀砖尖拱，两根拱脚上凿有蜂房，门槛已被磨得光滑。它连通巢脾的这一侧和那一侧，也就是说，哪里也不通。雄蜂排成一列从下面走过，蜂房里的蜡就是它们的脚印。

王台

一间六边形紫珀砖房，比其他蜂房都高，屋顶下悬着一只由蜡和琥珀结成的茧。茧已被撕开，里面是空的。女王不在了，此后再没有什么占据过她的巢室；最年长的保育蜂睡在茧下，守着它，仿佛她会回来。王浆封存在她周围的三个蜡室里。

潜影贝之巢

一个凹凸不平的巢脾顶盖穹顶，顶上有一只眼，侧面有个被撕开的入口。里面，巢脾壁蜂房沿墙排列，潜影贝坐在上面和屋顶下，等待从洞口进来的任何东西。没有盾牌的人不会来这里，来过一次的也寥寥无几。

蜡厅

一座六边形的巢脾壁大厅，地面是浇注的蜡，四壁都是蜂房，有的封着，有的空着。潜影贝在这里一层又一层地长出蜡，直到南侧的墙角塌了，蜡流到了巢脾上。有两只从未离开。

蜡质深窟
又称“蜡质迷宫”

虫巢安定下来之前，潜影贝并不住在立柱上，而是住在立柱里面：在巢脾最厚处，它们啃出了四层六边形蜂房——蜡与琥珀的仓库、育幼室、守卫的回廊，以及最底下女王的居室。后来虫巢落定，潜影贝搬到了立柱上，并用蜡封住了旧巢脾。走不了的留了下来：雄蜂在蜂房间巡逻，幼虫啃食蜡，年老的保育蜂悬在茧下，女王在壳中沉睡，直到有人把她守卫的铭牌带给她。

蜡井

一口六边形的竖井，砖砌内壁，七格深，一道平台沿井壁盘旋而下。周围每一座巢脾的蜡都沿地面流到这里，越过井沿，淌进黑暗，在井底一层层凝结。井上的绞盘上还挂着它的炼药锅。

天气

  • 蜡质细雨。巢脾渗出蜡质，化作黏稠的雨滴；不穿宇航服在外面的人会被黏住。
  • 紫颂花粉。紫颂开花了，花粉飘在空气里。不穿宇航服吸入花粉的人，会不时被带出几步，就像吃了紫颂果一样。
  • 暖流。暖空气夹着琥珀色的火花从蜡井中升起：气温变暖，附近的植物生长速度提高到三倍。

事件

  • 虫巢苏醒。潜影贝从巢脾里爬出，雄蜂守卫着它们
  • 巢脾忆起飞翔。重力减弱；脚下的光环闪烁并将你托起。接住从地面升起的琥珀
  • 摇摆舞。一只雄蜂跳起八字舞：直线段指向一间封存的琥珀巢室。打开它，里面的守卫就会苏醒
