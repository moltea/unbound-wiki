Unbound维基

兼容性

本模组能与哪些模组良好配合：配方查看器、信息提示、Sodium 与 Iris、能量与标签。

配方查看器——JEI 与 REI

本模组的所有配方都能在查看器中看到：工作台与熔炉、本模组的机器（粉碎机、熔液泵、失重锻造坊、低温蒸馏器、船坞……）、祭坛供品和星门苏醒。没有配方的物品有一页“获取途径”：战利品、生物、密藏、交易、任务。有多种变体的物品——飞船蓝图、筑环者石板、遗孤记录、铜锈阶段——在查看器中逐个列出。JEI 与 REI 在两个加载器上都能使用。

“我在看什么”——Jade

Jade 会显示机器或管道里装着什么、是否在运转、装了哪些升级，守护者是否在沉睡，原住民是谁、有没有给你的任务。

其他模组的能量与流体

能量转换器把本模组的电网与其他模组（Tech Reborn、AE2、Powah）的能量连接起来：Fabric 上通过 Team Reborn Energy， NeoForge 上通过加载器的通用能量（FE）。在两个加载器上，本模组的流体都能流过其他模组的管道和储罐。在 NeoForge 上， Pipez 管道能直接从本模组的发电机和电池抽取能量（管道一侧设为抽取），并从其储罐抽取燃料。在两个加载器上，装有本模组流体的桶都能倒进其他模组的储罐，也能从中装满。

漏斗和其他模组的物品管道会把东西放进本模组机器的输入槽，并取出已完成的产物，两个加载器上都一样：模块、升级和火箭货物绝不会被管道抽走，即使管道没有指定面也不会；每个槽位放入的数量不超过机器窗口允许的上限（燃料厂的罐槽最多 16 个空罐）。

通用标签

本模组的物品都在通用 c: 标签中——其他模组的配方、机器和分拣器正是靠它们识别：

  • 矿石（c:ores）、粗矿（c:raw_materials）、锭（c:ingots）、粉（c:dusts）、宝石（c:gems）、存储方块（c:storage_blocks）、铜板与铜齿轮（c:plates、c:gears）；
  • 流体桶（c:buckets）、各世界的染色玻璃及其他玻璃（c:glass_blocks、c:glass_panes）；
  • 食物与饮品（c:foods——生肉与熟肉、汤、浆果；c:drinks）、盔甲（c:armors）与武器（c:tools）；
  • 世界主宰与巢穴守护者在实体标签 c:bosses 中：其他模组的陷阱和传送器不会碰它们。

本模组的每个物品标签在模组支持的每种语言中都有名称：配方查看器显示的是“钛锭”或“铅矿石”，而不是 #c:ingots/titanium。由加载器自己命名的通用标签（c:ingots、c:ores）保留加载器的名称。

本模组的粉碎机按同样的标签处理其他模组的粗矿；粉碎机和失重锻造坊的配方都是普通的数据包配方：任何数据包或模组都能添加自己的配方。

Sodium、Iris 与光影包

本模组可与 Sodium 和 Iris 一起使用。启用光影包时，本模组的后期效果（气候模糊、飞行特效）会自动关闭，天文望远镜的星空绘制在画面之上——其余一切照常。在 Sodium 的视频设置中，本模组有自己的“模组画质”页（画质等级和“模组设置……”按钮）—— Fabric 与 NeoForge 上皆有。

已在 Fabric 和 NeoForge 上用 Complementary Reimagined 光影包测试（NeoForge 上用的是 Iris for NeoForge；Oculus 和 Embeddium 没有适配这个游戏版本的构建）。在无空气的世界和太空中（月球、水星、冥王星、太空、地渊），光影包被有意不启用，因此本模组的天空与不装光影包时看起来一样。在其他世界，光影包会画出自己那种类似地球的天空和云。光影包不读取气态巨行星云层中的雾，所以本模组自己铺雾：在云中，七格以外的一切都会融入云的颜色，与不装光影包时一样，云中矿石的闪光会显示在雾气之上。

天空模组

改变天空的模组（ATMOSPHERICS 之类）在地球和其他模组的世界中生效，而本模组自己的世界、太空和天文望远镜保留各自的天空—— 有行星、卫星、星环和星云。已在 Forge 1.20.1 上用 ATMOSPHERICS 2.6.8 测试。

便利模组

  • Trinkets Updated——饰品槽，用来佩戴各世界的神器和行囊（Fabric 与 NeoForge）。
  • Curios（NeoForge）——同上：戒指、项链、腰带、背部（行囊、来客之帆）、头部（筑环者透镜）；两个饰品槽模组都装时，两者的槽位都能用。需要 Curios 17.0.0-beta.3 或更新版本：更早的 26.3 测试版无法在当前的 NeoForge 上启动。Curios 窗口用 G 打开——与装备详情是同一个键：在神器上按住 G 打开它的详情，不在物品上时按 G 则关闭窗口。提示文本会写出你装的是哪个饰品槽模组；一个都没装时，神器无法佩戴，行囊可直接在物品栏中使用。
  • NeoForge 上的按键设置。NeoForge 26.3（测试版）会把许多游戏自带的按键标成黄色——向左平移、打开聊天栏、数字键：它们与 F3 调试组合键共用字母，加载器把这算作冲突。本模组的按键不会被标出——判断方式与游戏本身和 Fabric 相同： G 键的装备详情和 H 键的望远镜提示既不妨碍 F3+G 和 F3+H，也不妨碍快捷操作；只有你把某个键改绑到已被占用的键上时才会出现标记。
  • Mod Menu——在 Fabric 上从模组列表打开模组设置；在 NeoForge 上，同样的按钮就在加载器自己的模组列表里，无需额外模组。
  • AppleSkin——本模组食物的饱和度。
  • 地图模组（Xaero’s、JourneyMap）和整理模组（Inventory Profiles Next、Mouse Tweaks）可在本模组的界面中正常使用。

给附属模组作者

附属模组可以通过本模组的 Java API 添加自己的日志节点、世界、星座、事件和星门条件，无需 Mixin——见“附属模组”。
