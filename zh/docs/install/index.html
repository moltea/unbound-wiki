选哪个文件

模组共有六个文件：每个 Minecraft 版本和加载器各一个。游戏版本和加载器写在文件名里：

MinecraftFabricNeoForgeJava
26.3…-fabric-26.3-<version>.jar（约 18 MB）…-neoforge-26.3-<version>.jar（约 20 MB）25
1.21.1…-fabric-1.21.1-<version>.jar（约 18 MB）…-neoforge-1.21.1-<version>.jar（约 20 MB）21
1.20.1…-fabric-1.20.1-<version>.jar（约 18 MB）…-forge-1.20.1-<version>.jar（约 21 MB），也适用于 Forge17

所有文件内容相同，按你的游戏版本和加载器装对应的那个即可。没有同时适用于 Fabric 和 NeoForge、或适用于多个游戏版本的单一 jar；在 1.20.1 上，那一个 …-forge-… 文件可同时运行于 Forge 47 和 NeoForge 47.1。在 1.21.1 和 1.20.1 上，有几处外观或玩法略有不同：原版云更稀疏（这两个版本就是这样绘制云的），外太空中的星星稍小，在 NeoForge 1.21.1 和 Forge 1.20.1 上神器只能放进 Curios 栏位。这两个版本没有铜粒，因此粉碎机不会把铜板、线束或铜线圈拆成铜粒，黑烟囱蟹也不会掉落铜粒。存档不能在不同游戏版本之间迁移。

每个文件都带有对应加载器的模组描述，启动器和网站会自动显示名称、版本和加载器。在 NeoForge 的模组列表里，模组旁边还有一行标着“(resources)”——这是它自己的资源，嵌套在同一个 jar 中：无需另外安装任何东西。

Fabric

  1. 安装对应 Minecraft 版本的 Fabric Loader。
  2. 把本模组的 Fabric 文件、Fabric API 和 Fabric 版 GeckoLib（模组的模型和动画）放进 mods 文件夹——三者须对应同一 Minecraft 版本。1.21.1 上为 GeckoLib 4（4.9.3 或更高），1.20.1 上为 GeckoLib 4（4.8.4 或更高）， 26.3 上为 GeckoLib 5。
  3. 用 Fabric 配置启动游戏。Java 必须是表中列出的版本。

模组设置——通过 Mod Menu（如已安装）或星辰日志中的齿轮按钮打开。

NeoForge

  1. 安装对应你 Minecraft 版本的 NeoForge：1.21.1 用 21.1，26.3 用 26.3——26.3 的 NeoForge 仍处于测试版。
  2. 把本模组的 NeoForge 文件和 NeoForge 版 GeckoLib 放进 mods 文件夹（1.21.1 上为 GeckoLib 4，26.3 上为 GeckoLib 5）。不需要其他东西。
  3. 用 NeoForge 配置启动游戏。

模组设置——模组列表里的“配置”按钮或日志中的齿轮按钮。机器能量使用 NeoForge 的通用能量（FE），流体和物品使用 NeoForge 的传输接口：其他模组的线缆、管道和储罐都能接到机器上，与 Fabric 上一样。

1.20.1 上的 Forge 和 NeoForge

  1. 安装 Minecraft 1.20.1 的 Forge 47 或 NeoForge 47.1。需要 Java 17。
  2. 把 …-forge-1.20.1-<version>.jar 文件和 Forge 版 GeckoLib（4.8.4 或更高）放进 mods 文件夹。不需要其他东西。
  3. 用 Forge 或 NeoForge 配置启动游戏。

Forge 上的机器能量为 Forge 通用能量（FE），流体和物品使用 Forge 的传输接口，与上文 NeoForge 相同。

语言

本模组支持英语、俄语，以及自 0.15.2 起的简体中文：物品、日志、各族对话、界面和字幕。模组跟随游戏语言；中文翻译暂缺的文本以英语显示。本维基同样提供这三种语言，可在页首切换。

可选模组

JEI、REI、Jade、Sodium 搭配 Iris（Forge 1.20.1 上改用 Embeddium 和 Oculus）在所有加载器和游戏版本上都能使用—— 请选用为你的 Minecraft 版本制作的版本。神器栏位（神器、行囊和筑环者透镜）：

  • 26.3：两个加载器上都可用 Trinkets Updated；NeoForge 上还可用 Curios 17.0.0-beta.3 或更高（更早的 26.3 测试版在当前 NeoForge 上无法启动）。两个栏位模组可以同时安装。
  • 1.21.1：Fabric 上用 Trinkets 3.10；NeoForge 上用 Curios 9——Trinkets 没有 1.21.1 的 NeoForge 版本。
  • 1.20.1：Fabric 上用 Trinkets 3.7；Forge 和 NeoForge 上用 Curios 5。

它们各自添加了什么、检验过哪些版本——见“兼容性”。

在服务器上

本模组服务器和每位玩家的客户端都要安装：规则和状态在服务器上，客户端负责绘制。服务器和玩家使用同一个文件——相同的加载器、相同的 Minecraft 版本：Fabric 客户端无法加入 NeoForge 服务器， 1.21.1 客户端无法加入 26.3 或 1.20.1 服务器，反之亦然。详见 “在服务器上游玩”；该页还有一小节写给管理员：模组的命令，以及模组如何在专用服务器上接受检验。

无法启动

  • class file version 69.0 … up to 65.0。错误 java.lang.UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0 表示游戏是用旧版 Java 启动的：69 是 Java 25，65 是 Java 21。Minecraft 26.3 需要 Java 25，出错的是游戏本身，在任何模组加载之前（Minecraft 1.21.1 运行于 Java 21，1.20.1 运行于 Java 17）。请安装 Java 25（例如从 Adoptium 获取），并在启动器的安装配置中选中它；官方启动器和大多数其他启动器会自动选对 Java。服务器上——见“服务器无法启动”。
  • Fabric：弹出“Incompatible mods found!”窗口，其中有一行 requires version … or later of fabric-api, which is missing （或 … of geckolib …）——mods 文件夹里没有 Fabric API 或 GeckoLib。加载器会告诉你该装什么： Install geckolib, version 5.5.7 or later。
  • NeoForge：requires geckolib 5.5.7 or above. Currently, geckolib is not installed——mods 文件夹里没有 NeoForge 版 GeckoLib。
