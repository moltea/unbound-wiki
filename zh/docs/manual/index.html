使用手册

模组中一切事物的使用方法：步骤、按键与条件。

如何使用模组的机器、仪器、载具与地点：分步说明、按键、条件与限制，以及不起作用时的处理办法。这些页面与游戏内相同：星辰日志的“使用手册”页签，或在任意窗口中对物品按住 G。此处按键均为默认值——游戏内会显示你自己的设置。

起步

  • 天文台建筑套件 — 用于装饰望远镜小屋的方块。
  • 星辰日志 — 日志记录你的路线：下一步做什么、怎么做，以及你发现的一切。
  • 抛光透镜 — 光学零件：所有望远镜和许多仪器都从抛光透镜开始。
  • 折射望远镜 — 第一台望远镜：可观测月球、火星和最亮的星座。
  • 如何使用望远镜观测 — 观测时天空本身会改变：转动视角，把星星连成星座，对行星对焦。

仪器与实验室

  • 反射望远镜 — 第二台望远镜：放大三倍，可见直到木星的行星。
  • 天体照相仪与引力镜 — 两台太重而无法用三脚架的望远镜：它们立在方块底座上。
  • 熔岩镜 — 聆听下界之下的岩浆，寻找熔口——通往四个世界的道路。
  • 如何读取光谱 — 燃烧样品并显示其物质谱线；所知会解锁配方和仪器。
  • 摄谱仪：太阳与诸世界之光 — 捕捉天光，做和实验室相同的谜题：那里的空气由什么组成。
  • 矿物扫描仪 — 显示你已录入标准谱的矿脉。
  • 未知样品与弱点 — 可在实验室打开的发现，以及告诉你如何重击生物的部件。
  • 建造射电望远镜 — 昼夜晴雨都能听见看不到的信号：地球、月球和太空皆可。
  • 射电信号：四种工具 — 每类信号都有对应的工具，地图下方的提示行会告诉你用哪个。
  • 稀有信号：成串与蓬托斯 — 按时钟出现的两种信号：通往磁星与塔拉西亚。
  • 三路干涉仪 — 三条路线上的三台射电望远镜合成一夜的银河中心影像。
  • 裂隙镜 — 窥视末地的虚空并寻找裂隙——通往四个世界的道路。

能量与机器

  • 第一个电网 — 从第一台发电机到运转的机器：相邻传能与光束。
  • 燃煤发电机 — 燃烧任何熔炉燃料并转化为能量。
  • 机器各面与红石 — 设置漏斗、管道与能量从哪一面进出，以及如何关闭机器。
  • 太阳能板 — 利用日光发电，无需燃料。
  • 电池块 — 储存多余能量并在需要时放出；也给火箭用的便携电池充电。
  • 感应发射器 — 无需光束为球形范围内的机器供能。
  • 纠缠共振器 — 在任意距离乃至世界之间传输能量。
  • 能量转换器与其他模组 — 光束电网与其他模组电缆、机器之间的桥梁。
  • 重力发生器 — 在周围球形范围内维持你设定的重力。
  • 机器版本与升级卡 — 更高版本更快更大；升级卡改变某一项属性。
  • 万用表与压力计 — 显示电网与管道内的情况。
  • 粉碎机 — 一份粗矿得两份矿粉；外星岩石可得玻璃、盐与燃料。
  • 熔液泵 — 从熔融的海与湖中抽取金属和晶体。
  • 火焰分离器 — 燃烧赫墨拉油，把塔拉西亚粗矿变成你选择的家乡矿物。
  • 燃料厂 — 用煤制火箭燃料、用月壤制氦-3，无需能量。
  • 充电站与电池 — 用阳光给便携电池和多用工具充电。
  • 燃料库 — 储存一种液体燃料并经燃料管道分配。
  • 液体与桶 — 每种液体的来源、取法与用途。
  • 珍珠液化器 — 把末影珍珠融成液态珍珠——裂隙穿梭机的燃料。
  • 低温蒸馏器 — 用冰与岩浆膏制成冷却液——潜钟的燃料。
  • 机器的通用规则 — 所有机器的共同点：能量、接口面、漏斗、红石、升级。
  • 电炉 — 能冶炼熔炉可冶炼的一切，速度两倍且不用煤。

空气、宇航服与气候

  • 生物反应器 — 把植物变成氧气：基地与宇航服的第一个空气来源。
  • 电解器 — 把水分解成氧气和火箭用的氢；没有冰的地方可从土壤提取氧气。
  • 密封房间与气闸 — 任何世界里充满空气的房间：不穿宇航服也能呼吸，不受冷热与酸侵扰。
  • 氧气穹顶 — 无需墙壁就能维持一团空气：可呼吸、种树苗、放重生床。
  • 酸液中和器 — 让金星与“吐息”的空气不再腐蚀基地周围的你。它不产氧。
  • 水培床 — 无需土壤、水、空气和光照就能种作物——让基地的空气自给自足。
  • 宇航服架 — 给宇航服胸甲安装模块，并补充氧气与电量。
  • 宇航服模块：按世界选装 — 胸甲的四个插槽决定你能在哪里、活多久。
  • 宇航服与氧气 — 在其他世界，没有空气和完整宇航服只能活几秒。

仓储与基地

  • 仓储：终端与单元 — 所有物品集中于一个可搜索排序的界面。
  • 从仓储合成 — 仓储界面内的合成网格：材料直接取自仓储。
  • 气动邮递 — 用胶囊在箱子与机器之间经管道送物品。
  • 自动装配机 — 按配方卡反复合成指定物品。
  • 世界间货运通道 — 连接两个世界的仓储：可查看并取用远端物品。
  • 电梯 — 在楼层间载人的轿厢。
  • 传送信标 — 在同一世界的基地之间传送你。
  • 快递无人机 — 无人机在两个容器间送物，适合管道难到处。
  • 行囊 — 随身储物，还可补给宇航服。

火箭与载具

  • 加注塔 — 用软管从燃料管道直接为火箭、穿梭机或潜钟加注。
  • 充电塔 — 直接从电网为发射台上的火箭充电。
  • 星图与航行 — 在火箭座舱里通过星图选择世界并发射。
  • 建造火箭 — 火箭在发射台上逐块搭建；每一代飞得更远。
  • 火箭模块 — 模块装在船体接口上，决定你能否返航。
  • 裂隙梭舟 — 从末地穿过已打开的裂隙前往四个世界，并沿丝线免费返回。
  • 下潜钟 — 从下界穿过熔岩潜入熔口底部的四个世界；绞盘免费拉它回家。
  • 漫游车 — 用于外星地面的车辆：座位、货箱、周围空气；可折叠成口袋胶囊。

星舰与货舰

  • 驾驶星舰 — 起飞、飞出天空进入太空、降落——以及座舱按键说明。
  • 跃迁与星系图 — 四秒跨越数千格。
  • 船坞：建造飞船 — 船坞可建造飞船、提升等级并拆解。
  • 飞船控制台 — 一个界面：货舱、模块、燃料、维修、朋友和活体货物。
  • 飞船朋友与船员 — 允许其他玩家登船、驾驶或使用控制台——即使你不在线。
  • 召舰信标 — 把你的飞船从任何地方召来。
  • 飞船模块 — 模块让飞船更快、更坚固、更能装；每种有三级。
  • 提升飞船等级 — C → B → A → S：每级让同一艘船全面变强。
  • 飞船甲板 — 每艘飞船都有可在飞行中行走的内舱。
  • 自动驾驶 — 在你走动时自动驾驶飞船穿越太空。
  • 星系图 — 俯视你所在的空域：世界、环带、空间站和你的发现。
  • 着陆信标 — 飞船从太空直接进入它上方的天空，不再离家数千格。
  • 活体货物 — 用飞船在世界间运送动物、村民等生物。
  • 飞船间换乘 — 光桥把你送到旁边的另一艘飞船。
  • 打捞：把飞船装入货舱 — 捕获光束把无人飞船收进货舱，无需模块。
  • 拖曳 — 光索拖曳有人的飞船，或装不进货舱的飞船。
  • 环带矿石与采矿光束 — 太空中悬浮着各世界没有的矿石：用镐或从驾驶舱开采。
  • 失事飞船 — 旧探险队的残骸：箱子、故事，有时还有可修复的飞船。
  • 飞船武器 — 脉冲炮：瞄哪打哪，瞬间命中。
  • 重型武器与护盾 — 穿透弹、追踪鱼雷，以及先于船体承伤的护盾。
  • 诸路武器 — 虚空长矛、熔渣高射炮，以及对付鱼雷的干扰弹。
  • 货船：停靠、钥匙与跃迁 — 承载你的飞船、仓库和基地、随叫随到的主力舰。
  • 货船甲板 — 内部：机库、建造大厅、联网货舱、船员舱室和可观太空的舰桥。
  • 购买与交换货船 — 每座民族空间站每天售三艘货船，并接受以旧换新。
  • 求救信号 — 从流浪者手中救下货船——首艘归你所有。
  • 舰队与远征 — 护卫舰跟随货船并自行远征，即使你离线。

世界、种族与地牢

  • 村庄职业 — 五种新职业的村民，工作方块是本模组的设备。
  • 原住民：交谈与交易 — 每个世界都有自己的种族：可以交谈、交易、买地图、接任务。
  • 原住民任务 — 原住民会给任务：带来、击败、寻找、经历、递送——报酬是别处买不到的东西。
  • 寻找异界建筑 — 世界中的建筑里藏着当地战利品和关于该地的日志页。
  • 地牢：寻找、进入、通过 — 世界的地牢有数层，每层有上锁的大门和守卫，最深处是主宰与宝库。
  • 地牢：封印与机关 — 地牢与遗迹的封印在等待什么，各种机关如何运作。
  • 地牢：各有特色机关 — 每个大型地牢都有贯穿各层的独特机关，变化前 3–6 秒可见可闻。
  • 世界主宰：召唤与击败
  • 巢穴守护者
  • 诸界星门 — 已苏醒的星门相连：从任意一座可走到另一座，收取少量费用。
  • 诸界事件 — 每隔数日世界会发生大事件；留到结束的人便算经历了它。
  • 诸界天气 — 天气自行来去，略微改变世界：能见度、风、温度、空气。
  • 诸界矿石：何处与如何开采 — 每个世界有两三种自己的矿石，长在当地岩石里，几乎一切都要用它支付。

  • 繁殖异界野兽 — 有些野兽会从你手中吃东西，喂饱的一对会产仔——只在自己的世界。
  • 驯服与骑乘 — 反复喂食可驯服的生物直到它信任你；配上该世界的鞍具，它会在陆上、空中或水中载你。

  • 陨石：寻找与挖掘 — 每隔数日陨石坠落在荒野、远离住所处，留下陨坑、金属和星尘。
  • 天空之心 — 并非石头的巨型陨石：夜间露天时积攒星尘。
  • 前往塔拉西亚之路 — 塔拉西亚是赫墨拉星旁的第二个地球；入口在木星特洛伊群旁，首艘星舰即可。
  • 塔拉西亚人与他们的田地 — 塔拉西亚人住在浅滩上方的草地聚落，出售第二地球的有用之物。
