Установка

Что нужно, чтобы играть с модом, — на Fabric и NeoForge, в одиночку и на сервере.

Fabric
Minecraft26.3
Java25
Fabric Loader0.19.5+
Fabric API0.161.0+26.3
GeckoLib5.5.7+
NeoForge
Minecraft26.3
Java25
NeoForge26.3.0.64-beta+
GeckoLib5.5.7+
Необязательно, но мод с ними дружит
  • JEI — рецепты станков, источники предметов (оба загрузчика)
  • REI / EMI — то же на Fabric
  • Jade — что внутри механизма, трубы, врата, жители
  • Trinkets Updated — гнёзда для артефактов: кольцо, подвеска, пояс (один мод на оба загрузчика)
  • Mod Menu — настройки мода из списка модов на Fabric (на NeoForge — кнопка «Настройки» в списке модов)
  • Sodium / Iris — совместимы; с набором шейдеров постэффекты мода выключаются
  • Энергия и трубы — кабели, трубы и баки других модов подключаются к механизмам: Team Reborn Energy на Fabric, энергия и передача NeoForge (FE) на NeoForge

Какой файл брать

Мод выходит двумя файлами — под каждый загрузчик свой: …-fabric-26.3-<версия>.jar (около 17 МБ) и …-neoforge-26.3-<версия>.jar (около 19 МБ). Возможности у них одинаковые; ставится тот, что под ваш загрузчик. Один jar на оба загрузчика не делается.

Оба файла несут описание мода для своего загрузчика, поэтому лаунчеры и сайты сами показывают название, версию и загрузчик. В списке модов NeoForge рядом с модом стоит вторая строка с пометкой «(resources)» — это его же ресурсы, вложенные в тот же jar: отдельно ставить ничего не нужно.

Fabric

  1. Установите Fabric Loader для нужной версии Minecraft.
  2. Положите в папку mods файл мода для Fabric, Fabric API и GeckoLib для Fabric (модели и анимации мода).
  3. Запустите игру с профилем Fabric. Java нужна той версии, что указана в таблице.

Настройки мода — через Mod Menu (если он стоит) или шестерёнкой в звёздном журнале.

NeoForge

  1. Установите NeoForge под Minecraft 26.3 — под эту версию у NeoForge пока бета.
  2. Положите в папку mods файл мода для NeoForge и GeckoLib для NeoForge. Больше ничего обязательного.
  3. Запустите игру с профилем NeoForge.

Настройки мода — кнопкой «Настройки» в списке модов или шестерёнкой в журнале. Энергия механизмов — общая энергия NeoForge (FE), жидкости и предметы — передача NeoForge: кабели, трубы и баки других модов подключаются к механизмам, как на Fabric.

Необязательные моды

JEI, REI, Jade, Sodium с Iris и Trinkets Updated работают на обоих загрузчиках. На NeoForge мод поддерживает и Curios (артефакты, ранец и Линза Ставивших встают в его гнёзда) — нужен Curios 17.0.0-beta.3 или новее: более ранние беты под 26.3 с текущим NeoForge не запускаются. Можно поставить и оба мода гнёзд сразу. Подробнее, что они дают, — «Совместимость».

На сервере

Мод ставится и на сервер, и каждому игроку: правила и состояние живут на сервере, клиент рисует. Загрузчик у сервера и у игроков один и тот же: клиент Fabric на сервер NeoForge не войдёт, и наоборот. Подробнее — «Игра на сервере»; там же коротко для администратора: команда мода и как мод проверен на выделенном сервере.

Не запускается

  • class file version 69.0 … up to 65.0. Ошибка java.lang.UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0 значит, что игра запущена на старой Java: 69 — это Java 25, 65 — Java 21. Minecraft 26.3 нужна Java 25, и падает сама игра, ещё до модов. Поставьте Java 25 (например, с Adoptium) и выберите её в настройках установки лаунчера; официальный лаунчер и большинство других ставят нужную Java сами. На сервере — см. «Сервер не запускается».
  • Fabric: окно «Incompatible mods found!» со строкой requires version … or later of fabric-api, which is missing (или … of geckolib …) — в папке mods нет Fabric API или GeckoLib. Загрузчик сам пишет, что поставить: Install geckolib, version 5.5.7 or later.
  • NeoForge: requires geckolib 5.5.7 or above. Currently, geckolib is not installed — в папке mods нет GeckoLib для NeoForge.
