Какой файл брать

Мод выходит шестью файлами — под каждую версию Minecraft и каждый загрузчик свой; версия игры и загрузчик — в имени файла:

MinecraftFabricNeoForgeJava
26.3…-fabric-26.3-<версия>.jar (около 18 МБ)…-neoforge-26.3-<версия>.jar (около 20 МБ)25
1.21.1…-fabric-1.21.1-<версия>.jar (около 18 МБ)…-neoforge-1.21.1-<версия>.jar (около 20 МБ)21
1.20.1…-fabric-1.20.1-<версия>.jar (около 18 МБ)…-forge-1.20.1-<версия>.jar (около 21 МБ), он же для Forge17

Содержимое у всех одинаковое; ставится тот, что под вашу версию игры и ваш загрузчик. Один jar на Fabric и NeoForge или на разные версии игры не делается; на 1.20.1 один файл …-forge-… идёт и на Forge 47, и на NeoForge 47.1. На 1.21.1 и 1.20.1 немногое выглядит и работает чуть иначе: облака игры реже (так их рисуют сами эти версии), звёзды в космосе чуть мельче, а артефакты на NeoForge 1.21.1 и на Forge 1.20.1 надеваются только в гнёзда Curios. Медного самородка в этих версиях нет, поэтому там дробилка не разбирает Медный лист, Проводку и Медную катушку на самородки, а Краб курильщиков их не роняет. Мир между версиями игры не переносится.

Оба файла несут описание мода для своего загрузчика, поэтому лаунчеры и сайты сами показывают название, версию и загрузчик. В списке модов NeoForge рядом с модом стоит вторая строка с пометкой «(resources)» — это его же ресурсы, вложенные в тот же jar: отдельно ставить ничего не нужно.

Fabric

  1. Установите Fabric Loader для нужной версии Minecraft.
  2. Положите в папку mods файл мода для Fabric, Fabric API и GeckoLib для Fabric (модели и анимации мода) — все три под одну версию Minecraft. Под 1.21.1 это GeckoLib 4 (4.9.3 или новее), под 1.20.1 — GeckoLib 4 (4.8.4 или новее), под 26.3 — GeckoLib 5.
  3. Запустите игру с профилем Fabric. Java нужна той версии, что указана в таблице.

Настройки мода — через Mod Menu (если он стоит) или шестерёнкой в звёздном журнале.

NeoForge

  1. Установите NeoForge под свою версию Minecraft: 21.1 — под 1.21.1 или 26.3 — под 26.3 у NeoForge пока бета.
  2. Положите в папку mods файл мода для NeoForge и GeckoLib для NeoForge (под 1.21.1 — GeckoLib 4, под 26.3 — GeckoLib 5). Больше ничего обязательного.
  3. Запустите игру с профилем NeoForge.

Настройки мода — кнопкой «Настройки» в списке модов или шестерёнкой в журнале. Энергия механизмов — общая энергия NeoForge (FE), жидкости и предметы — передача NeoForge: кабели, трубы и баки других модов подключаются к механизмам, как на Fabric.

Forge и NeoForge на 1.20.1

  1. Установите Forge 47 или NeoForge 47.1 под Minecraft 1.20.1. Нужна Java 17.
  2. Положите в папку mods файл …-forge-1.20.1-<версия>.jar и GeckoLib для Forge (4.8.4 или новее). Больше ничего обязательного.
  3. Запустите игру с профилем Forge или NeoForge.

Энергия механизмов на Forge — общая энергия Forge (FE), жидкости и предметы — передача Forge, как у NeoForge выше.

Языки

Мод говорит по-английски, по-русски и, с 0.15.2, на упрощённом китайском (简体中文): предметы, журнал, разговоры народов, окна и субтитры. Язык — как у игры; чего в китайском переводе ещё нет, показывается по-английски. Вики — на тех же трёх языках, переключатель — в шапке.

Необязательные моды

JEI, REI, Jade, Sodium с Iris (на Forge 1.20.1 вместо них Embeddium и Oculus) работают на всех загрузчиках и версиях игры — берутся версии под ваш Minecraft. Гнёзда для артефактов (артефакты, ранец и Линза Ставивших):

  • 26.3: Trinkets Updated на обоих загрузчиках; на NeoForge — ещё и Curios 17.0.0-beta.3 или новее (более ранние беты под 26.3 с текущим NeoForge не запускаются). Можно поставить и оба мода гнёзд сразу.
  • 1.21.1: Trinkets 3.10 на Fabric; Curios 9 на NeoForge — Trinkets под NeoForge 1.21.1 нет.
  • 1.20.1: Trinkets 3.7 на Fabric; Curios 5 на Forge и NeoForge.

Подробнее, что они дают и какие версии проверены, — «Совместимость».

На сервере

Мод ставится и на сервер, и каждому игроку: правила и состояние живут на сервере, клиент рисует. Файл у сервера и у игроков один и тот же — тот же загрузчик и та же версия Minecraft: клиент Fabric на сервер NeoForge не войдёт, клиент 1.21.1 на сервер 26.3 или 1.20.1 — тоже, и наоборот. Подробнее — «Игра на сервере»; там же коротко для администратора: команда мода и как мод проверен на выделенном сервере.

Не запускается

  • class file version 69.0 … up to 65.0. Ошибка java.lang.UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0 значит, что игра запущена на старой Java: 69 — это Java 25, 65 — Java 21. Minecraft 26.3 нужна Java 25, и падает сама игра, ещё до модов (Minecraft 1.21.1 идёт на Java 21, 1.20.1 — на Java 17). Поставьте Java 25 (например, с Adoptium) и выберите её в настройках установки лаунчера; официальный лаунчер и большинство других ставят нужную Java сами. На сервере — см. «Сервер не запускается».
  • Fabric: окно «Incompatible mods found!» со строкой requires version … or later of fabric-api, which is missing (или … of geckolib …) — в папке mods нет Fabric API или GeckoLib. Загрузчик сам пишет, что поставить: Install geckolib, version 5.5.7 or later.
  • NeoForge: requires geckolib 5.5.7 or above. Currently, geckolib is not installed — в папке mods нет GeckoLib для NeoForge.
