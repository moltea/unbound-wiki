Игра на сервере

Мод на выделенном сервере: установка, игра вдвоём и нагрузка.

Мод сделан для игры с друзьями: всё работает на выделенном сервере с несколькими игроками.

  • Ставится на сервер и каждому игроку — те же версии мода и зависимостей и тот же загрузчик, Fabric или NeoForge (см. «Установка»).
  • У каждого свой путь: журнал, найденные миры, скафандр, задания и репутация у народов — у каждого игрока свои. Миры, постройки и врата — общие.
  • Вдвоём можно лететь в одной ракете, ходить на корабле с экипажем, пересаживаться к другу и вытаскивать сбитый корабль буксиром.
  • Кресло ждёт вышедшего: если вы вышли из игры в корабле, где летели не одни, место остаётся за вами — при входе вы снова на борту, в своём кресле, где бы корабль к тому времени ни оказался. Перезапуск сервера экипаж тоже переживает: корабль на месте, все в креслах. Один на борту — корабль, как и прежде, уходит из мира вместе с вами и возвращается с вами. То же в ракете, челноке Края и колоколе Незера с пассажирским креслом: вышли на взлёте — вернётесь в кресло, где бы аппарат ни летел; аппарат успел сесть без вас — выйдете у него, рядом с остальными. Если транспорта больше нет (корабль погиб, пока вас не было), вас перенесёт в безопасное место — на землю рядом или к вашей точке возрождения, — а если кресло заняли, корабль пустит вас на борт, на палубу. Об этом скажет строка на экране.
  • Лёгкий для сервера: мод не обходит все блоки и сущности каждый такт, тяжёлое делает реже и по событию, пакеты шлёт только по перемене. Это проверяется замером на сервере с игроками.
  • Быстрый полёт не держит сервер: чанки по курсу корабля готовятся заранее, а там, где они ещё рождаются, сервер не ждёт их посреди такта. Свет растущих островов и лучи боссов уходят игрокам экономно — одним пакетом и ключами.
  • Клиент только рисует и шлёт намерения — решает сервер: найден ли мир, засчитан ли этап, долетела ли ракета.

Администратору

Проверено вдвоём. Перед выпуском весь мод проходят двое на настоящем выделенном сервере, на Fabric и на NeoForge: 63 сцены — от входа и окон механизмов до кораблей, малых миров и их событий, дальних дорог и финала, с выходами посреди полёта, обрывами связи и перезапуском сервера. После обрыва и перезапуска сверяется всё, что есть у игрока: мир и место, прогресс, скафандр, задания, инвентарь, корабль под ним.

Остановка посреди боя с «Вольной гаванью». Логово перелётчиков на Деймосе помнит в данных мира, сколько его кораблей и турелей ещё не сбито и кто сколько урона им нанёс. После перезапуска сервера недобитые защитники выходят снова, а доли тех, кто бил до остановки, целы. Ключ журнала за разорение гавани ждёт и того, кто бил её защитников, но в миг падения был не в игре: он получит его через несколько секунд после входа. Сами вещи доли лежат у гавани двенадцать минут (обломки сбитого перелётчика — три), и перезапуск сервера их не стирает: трофеи записаны в данные мира, доля ждёт своего игрока, чужую не взять — подлетите на корабле, и она уйдёт в трюм.

Команда мода одна, называется так же, как id мода, и требует прав оператора. От имени игрока её отдают через execute as <игрок> run ….

КомандаЧто делает
progress grant <ключ>засчитывает один ключ прогресса: вернуть потерянное. progress complete и progress reset — весь путь журнала разом
raid [сколько] [warn]перелётчики выходят на корабль отдавшего команду — засадой сразу или налётом после предупреждения. Нужен пилот в выживании в открытом космосе, не у станции
act flight [x y z] <мир>«лететь» в ракете, челноке или колоколе (без места — ближайшая кабина), со всеми проверками игры
act jump <тело>, act far auto|back <цель>прыжок корабля; стежок, нырок и возвращение по метке
act lairгде логово перелётчиков и что с ним: сколько защитников не сбито и сколько в поле, сколько игроков в доле, кому гавань должна ключ; сколько долей трофеев ждёт в космосе и сколько в них вещей

Сервер не запускается

class file version 69.0 … up to 65.0. Если сервер падает сразу, а в консоли стоит java.lang.UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0 (на Fabric строкой выше — An exception occurred when launching the server!), сервер запущен на Java 21, а Minecraft 26.3 нужна Java 25: 69 — это Java 25, 65 — Java 21. Мод тут ни при чём — так же падает и сервер без модов. Поставьте Java 25 и укажите её: на хостинге — в панели (версия Java или образ с Java 25), на своей машине — полным путём к java в команде запуска (у NeoForge — в run.sh или run.bat). Какая Java запускается, покажет java -version.

Не хватает мода. Fabric: Incompatible mods found! и requires version … or later of fabric-api, which is missing (или … of geckolib …); NeoForge: requires geckolib 5.5.7 or above. Currently, geckolib is not installed. В папку mods сервера нужны те же обязательные моды, что и игрокам, — см. «Установка».
