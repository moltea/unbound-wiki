Installation

What you need to play with the mod — on Fabric and NeoForge, alone and on a server.

Fabric
Minecraft26.3
Java25
Fabric Loader0.19.5+
Fabric API0.161.0+26.3
GeckoLib5.5.7+
NeoForge
Minecraft26.3
Java25
NeoForge26.3.0.64-beta+
GeckoLib5.5.7+
Optional, the mod works well with them
  • JEI — machine recipes, item sources (both loaders)
  • REI / EMI — the same on Fabric
  • Jade — what is inside a machine, pipes, gates, natives
  • Trinkets Updated — slots for artifacts: ring, pendant, belt (one mod for both loaders)
  • Mod Menu — mod settings from the mod list on Fabric (on NeoForge — the Config button in the mod list)
  • Sodium / Iris — compatible; with a shader pack the mod’s post effects switch off
  • Energy and pipes — cables, pipes and tanks of other mods connect to the machines: Team Reborn Energy on Fabric, NeoForge energy and transfer (FE) on NeoForge

Which file to take

The mod ships as two files, one per loader: …-fabric-26.3-<version>.jar (about 17 MB) and …-neoforge-26.3-<version>.jar (about 19 MB). They have the same features; install the one for your loader. There is no single jar for both loaders.

Both files carry the mod description for their loader, so launchers and sites show the name, version and loader by themselves. In the NeoForge mod list a second line marked “(resources)” sits next to the mod — these are its own resources, nested in the same jar: nothing else needs installing.

Fabric

  1. Install Fabric Loader for the right Minecraft version.
  2. Put the mod’s Fabric file, Fabric API and GeckoLib for Fabric (the mod’s models and animations) into the mods folder.
  3. Launch the game with the Fabric profile. Java must be the version listed in the table.

Mod settings — via Mod Menu (if installed) or the gear in the Star Journal.

NeoForge

  1. Install NeoForge for Minecraft 26.3 — NeoForge is still in beta for this version.
  2. Put the mod’s NeoForge file and GeckoLib for NeoForge into the mods folder. Nothing else is required.
  3. Launch the game with the NeoForge profile.

Mod settings — the Config button in the mod list or the gear in the journal. Machine energy is NeoForge’s shared energy (FE), fluids and items use NeoForge transfer: cables, pipes and tanks of other mods connect to the machines, just as on Fabric.

Optional mods

JEI, REI, Jade, Sodium with Iris and Trinkets Updated work on both loaders. On NeoForge the mod also supports Curios (artifacts, the knapsack and the Ringwright Lens go into its slots) — you need Curios 17.0.0-beta.3 or newer: earlier betas for 26.3 do not start on the current NeoForge. You can also install both slot mods at once. What they add — see “Compatibility”.

On a server

The mod goes both on the server and on every player’s client: rules and state live on the server, the client draws. The server and the players use the same loader: a Fabric client cannot join a NeoForge server, and vice versa. More — “Playing on a server”; the same page has a short part for administrators: the mod’s command and how the mod is checked on a dedicated server.

It won’t start

  • class file version 69.0 … up to 65.0. The error java.lang.UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0 means the game was started with an old Java: 69 is Java 25, 65 is Java 21. Minecraft 26.3 needs Java 25, and it is the game itself that fails, before any mod loads. Install Java 25 (for example from Adoptium) and select it in your launcher’s installation settings; the official launcher and most others pick the right Java on their own. On a server — see “The server won’t start”.
  • Fabric: an “Incompatible mods found!” window with the line requires version … or later of fabric-api, which is missing (or … of geckolib …) — Fabric API or GeckoLib is not in the mods folder. The loader tells you what to install: Install geckolib, version 5.5.7 or later.
  • NeoForge: requires geckolib 5.5.7 or above. Currently, geckolib is not installed — GeckoLib for NeoForge is not in the mods folder.
